# 考研备考工作台（iPhone App 版）

专为 iPhone 优化的 PWA 应用，添加到主屏幕后像原生 App 一样全屏独立运行、有启动屏、可离线使用。

## 📁 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 主程序页面 |
| `manifest.json` | PWA 配置（名称、图标、主题色等） |
| `sw.js` | Service Worker，支持离线访问 |
| `icon-192.png` / `icon-512.png` | 桌面图标（浅蓝→浅粉渐变） |
| `apple-splash.png` | iPhone 启动屏 |
| `README.md` | 本说明文件 |

## 📲 iPhone 安装步骤（3 步）

> 必须用 **Safari** 浏览器打开，Chrome/微信内置浏览器无法添加到主屏幕

1. **用 Safari 打开网页**
   - 把 `app` 文件夹传到 iPhone（微信文件传输/QQ/网盘均可）
   - 或部署到网络后用 Safari 访问网址

2. **添加到主屏幕**
   - 点底部 **分享按钮** ⬆️
   - 滚动选择「**添加到主屏幕**」
   - 点「**添加**」

3. **从桌面图标打开**
   - 桌面出现「考研工作台」图标
   - 点开即全屏独立运行，无浏览器地址栏

首次用 Safari 打开时，页面会自动弹出图文引导提示，跟着做即可。

## ✨ iPhone 专属优化

- **启动屏**：打开瞬间显示浅蓝粉渐变 + 「研」字启动画面
- **全屏独立运行**：无 Safari 地址栏和工具栏，像原生 App
- **状态栏融合**：顶部状态栏与 app 主题色一致
- **离线可用**：Service Worker 缓存，没网也能查看和记录
- **桌面图标**：浅蓝→浅粉渐变圆角图标，显示「研」字
- **安装引导**：首次打开自动弹出添加到主屏幕的图文教程

## 🚀 部署到网络（推荐）

本地文件方式下，iOS 对 PWA 支持有部分限制（如 Service Worker 需 HTTPS）。
**部署到网络体验最佳**，免费方案：

| 服务 | 特点 |
|---|---|
| GitHub Pages | 免费、稳定、全球 CDN |
| Vercel | 一键部署、自动 HTTPS |
| Netlify | 拖拽上传、自动 HTTPS |
| Cloudflare Pages | 免费、速度快 |

部署后用 iPhone Safari 访问网址 → 分享 → 添加到主屏幕即可。

## ⚠️ 数据说明

- 所有数据**保存在 iPhone 本地**（localStorage）
- **卸载 App 或清除 Safari 数据会丢失**，建议每周用页面底部的「导出数据」备份
- 换新 iPhone 时，用「导入数据」恢复
